# 03 · OpenSEO

- **Reemplaza:** Semrush (y Ahrefs)
- **Qué es:** toolkit SEO open source: keywords, rank tracking, backlinks, auditoría de sitio, competencia, visibilidad en IA.
- **Para editar video:** investigar qué buscan para títulos/descripciones de YouTube y web; más útil si vendés servicios.
- **Repo:** https://github.com/every-app/open-seo
- **Licencia:** MIT
- **Costo real:** auto-hospedado es gratis, pero los datos vienen de **DataForSEO** (pago por uso, tu propia API key). El plan hosteado arranca ~US$10/mes según fuentes. No es 100% gratis.
- **Extra:** trae servidor MCP, se puede conectar a Claude Code.
- **Estado:** por probar (prioridad baja para edición pura)
