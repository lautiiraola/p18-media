# bases — herramientas gratis / open source para producir videos

Carpeta de "bases": herramientas que se usan **antes, durante y después** de la edición
(generar clips, voces, grabar pantalla, subtitular, y también gestionar clientes/proyectos).
Una subcarpeta por herramienta, con su ficha (`README.md`) y lugar para notas, clones o configs.

Fuente: reel de Instagram de @santiremedio (Santiago Remedio | Marketing con IA),
"9 repos de GitHub que reemplazan +US$5.000 en suscripciones" (la cifra es ilustrativa, dice el propio video).
Detalle en [`_fuente-video.md`](_fuente-video.md).

## Ojo con "gratis"

- "Open source" = el **software** es libre. Los **modelos de IA / APIs** que usan por detrás (video, voz, datos SEO)
  pueden cobrar por uso o pedir tu propia API key. Cada ficha lo aclara.
- Los repos de los puntos 2 y 5 hay que confirmarlos: el video dice el nombre solo de palabra (audio) y no lo muestra en pantalla.
- Antes de instalar algo, mirar licencia, último commit y estrellas del repo oficial (hay muchos forks con el mismo nombre).
