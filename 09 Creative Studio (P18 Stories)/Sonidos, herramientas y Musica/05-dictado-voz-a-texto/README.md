# 05 · Dictado / voz a texto

- **Reemplaza:** apps de dictado de pago (tipo Wispr Flow / Superwhisper)
- **Qué dice el video:** "lo que hace es dictar cualquier video y pasarlo (a texto)".
- ⚠️ **El nombre no aparece en pantalla**, solo en el audio. Confirmar.
- **Para editar video:** base para **subtítulos y transcripciones** de tus clips, y para dictar guiones.
