## Las skills (en orden)
0. **p18-analizar**: analiza un link y lo aprueba o no.
1. **p18-clipear**: saca los clips crudos de un video.
2. **p18-filtro**: le pone el formato P18 al clip → `Reels listos para subir`.
3. **p18-publicar**: caption, comentario, TikTok y la historia de repost de cada reel.
4. **p18-contenido**: cada 3 días, los posts (uno por reel), el carrusel del día y la frase del día.

Las carpetas `Reels listos para subir`, `Publicaciones listas para subir`, `Historias listas para subir`,
`Captions (respaldo)` y `Clips crudos` las usan las skills y la Biblioteca viva: **no les cambies el nombre**.
