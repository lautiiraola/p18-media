# Filtro de reels P18

Plantilla para pasar reels al formato P18 (1080x1920): fondo P18, logo, recuadro con el video, subtitulos lima y el titulo abajo.

- Plantilla/plantilla.html: el diseño. generar-capa.py arma la capa con el titulo de cada reel.
- Fuentes/: Manrope (500, 700, 800).
- Ejemplos y comparaciones/: las opciones que se probaron. Definitiva: opcion A (el recuadro se adapta al video). Alternativa guardada: opcion C.
- Archivos del video de Elon/: subtitulos (.ass), capa y audio del primer reel.

Videos terminados: carpeta 04 Instagram/Reels listos para subir.
